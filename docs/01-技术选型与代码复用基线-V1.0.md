# 技术选型与代码复用基线 V1.0

> 个人网关项目｜技术架构、成熟组件复用与云端实施基线\
> 实施模式：ChatGPT Work 云端开发 + GitHub 代码管理 + Vercel 部署\
> 日期：2026-07-31

## 1. 冻结结论

-   三大模块：工具与连接注册、AI客户端与发布授权、日志与告警。
-   API转MCP采用 Tool Registry + 通用Executor +
    动态Publication，不逐接口手写MCP代码。
-   技术栈：Next.js App Router、Ant Design 5、Supabase、Vercel、MCP
    TypeScript SDK。
-   GitHub是代码唯一事实源；Work负责云端开发、提交和触发Vercel Preview。

## 2. 核心对象

  对象          定义
  ------------- ---------------------------------
  Connection    具体外部账号或服务实例
  Tool          协议中立的AI可调用能力
  Executor      REST、MCP、IMAP等通用执行器
  Publication   以MCP或OpenAPI发布的一组工具
  AI Client     获得Publication访问授权的调用方

## 5. 必须自行开发

-   Tool、Connection、Publication、AI Client及关联关系。
-   executeTool、ToolResolver、PolicyGuard、ExecutorRegistry。
-   RestExecutor参数映射与结果转换。
-   远程MCP发现与选择性导入。
-   动态MCP和OpenAPI发布。
-   API Key、凭证加密、审计、异常规则、紧急停用。
-   H5响应式管理后台。

## 6. API转MCP运行链

``` text
MCP tools/call 或 Action Request
→ Publication
→ Tool Registry
→ PolicyGuard
→ ExecutorRegistry
→ CredentialService
→ ResultSanitizer
→ AuditWriter
```

## 7. Work实施规范

1.  每次任务先读取本文件和UI规范。
2.  使用 `work/prototype-*`、`work/feature-*`、`work/fix-*` 分支。
3.  小步提交GitHub，Vercel自动生成Preview。
4.  Preview验收后再合并main。
5.  不在聊天、代码和日志中放真实密钥。
6.  完成后运行lint、typecheck、测试和响应式检查。
